# Datos

Descargue una fotografía de alta resolución con licencia libre desde Unsplash,
Wikimedia u otra fuente compatible, y ejecute:

```bash
python3 scripts/preparar_imagenes.py ruta/a/foto.jpg
```

Para pruebas sin fotografía:

```bash
python3 scripts/preparar_imagenes.py --sintetica
```

El script genera las imágenes PGM de 2000, 4000 y 6000 píxeles.
